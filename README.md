## Featured Projects

### Airline Operations Intelligence

A hands-on enterprise AI engineering project exploring airline disruption management through flight delay propagation, with a roadmap toward governed lakehouse data, knowledge graphs, and agentic AI decision support. Includes a Python-based simulation engine, synthetic multi-aircraft scenarios, automated testing, and reproducible data exports.

**Focus areas:** Python, Databricks, Delta Lake, Unity Catalog, Knowledge Graphs, Amazon Neptune, Amazon Bedrock, Agentic AI, Data Engineering, Enterprise AI Architecture.

**Repository:** [airline-operations-intelligence](https://github.com/mickemora/airline-operations-intelligence)

### Airline On-Time Analytics Semantic Layer

An AWS-based semantic layer demonstrating how airline route reference data and flight performance records can be unified through a single GraphQL API. Uses governed, configurable on-time definitions to deliver consistent reliability, cancellation, and arrival-delay metrics to analytics applications, using reproducible synthetic flight data.

**Focus areas:** AWS AppSync, GraphQL, AWS Lambda, Amazon DynamoDB, Amazon S3, AWS CDK, Python, Semantic Layers, Data Governance, Airline Performance Analytics.

**Repository:** [airline-ontime-semantic-layer](https://github.com/mickemora/airline-ontime-semantic-layer)

### Airline Disruption Impact Graph — Amazon Neptune Serverless

A hands-on AWS graph engineering project demonstrating how airline disruptions propagate across interconnected aircraft, crew, and passenger operations. Built using Amazon Neptune Serverless, openCypher, AWS Lambda, and AWS CDK, the solution models operational dependencies, analyzes cascading flight delays, identifies missed passenger connections and crew duty-limit impacts, and evaluates alternative rebooking options using synthetic airline data.

**Focus areas:** Amazon Neptune Serverless, Graph Databases, openCypher, AWS Lambda, AWS CDK, Python, Graph Modeling, Operational Analytics, Airline Disruption Management.

**Repository:** [neptune-airline-disruption-graph](https://github.com/mickemora/neptune-airline-disruption-graph)

### Amazon Bedrock Multi-Agent

A solution design exploring how Amazon Bedrock Agents can use Lambda Action Groups to connect natural language workflows with backend business systems.

**Focus areas:** Amazon Bedrock Agents, AWS Lambda, DynamoDB, Action Groups, agent-to-tool integration, enterprise AI architecture.

**Repository:** [Amazon-Bedrock-MultiAgent](https://github.com/mickemora/Amazon-Bedrock-MultiAgent)

### Amazon Bedrock AgentCore — HelloAgent

A hands-on agentic AI engineering project demonstrating how to build, deploy, and securely integrate AI agents with enterprise services using Amazon Bedrock AgentCore. Progressed from local tool execution (V1) to an MCP-based architecture (V2) connecting a Strands AI agent to AWS Lambda through AgentCore Gateway, with IAM authentication and AWS CDK infrastructure management.

**Focus areas:** Amazon Bedrock AgentCore, Strands Agents, MCP, AgentCore Gateway, AWS Lambda, IAM/SigV4, AWS CDK, serverless architecture, secure agent-to-tool integration.

**Repository:** [bedrock-agentcore-hello-agent](https://github.com/mickemora/bedrock-agentcore-hello-agent)

### Amazon Bedrock Code Generation

A serverless GenAI prototype that uses AWS Lambda, Amazon Bedrock Runtime, Anthropic Claude, and Amazon S3 to generate and store code artifacts from high-level prompts.

**Focus areas:** Bedrock Runtime, Claude prompt design, Lambda orchestration, S3 artifact storage, AI-assisted software delivery.

**Repository:** [Amazon-Bedrock-Code-Generation](https://github.com/mickemora/Amazon-Bedrock-Code-Generation)
